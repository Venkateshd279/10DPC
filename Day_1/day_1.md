# Day 1

## Print Statements

Display text or values to the console:
```
print("Hello world")
print(a, b, c)
```

## Variables

Store values in memory with a name:
```
a = 10
b = 20
c = a  # c gets the value of a (10)
```

**Key Point:** Variables can hold any data type and can be changed anytime.

## Operators

### Arithmetic Operators

Used to perform mathematical operations:

#### 1. Addition (+)
```
a = 20
b = 10
print(a + b)  # Output: 30
```

#### 2. Subtraction (-)
```
a = 20
b = 10
print(a - b)  # Output: 10
```

#### 3. Multiplication (*)
```
a = 20
b = 10
print(a * b)  # Output: 200
```

#### 4. Division (//)
Floor division (integer division, ignores decimal part):
```
a = 20
b = 10
print(a // b)  # Output: 2
```

#### 5. Modulus (%)
Remainder after division:
```
a = 20
b = 10
print(a % b)  # Output: 0 (20 divided by 10 has no remainder)
```
