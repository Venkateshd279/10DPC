## Data Types

### Available Data Types in Python: 

#### 1. Numbers [int and float]

- **int**: Whole numbers (1, 2, 3, -5)
- **float**: Decimal numbers (2.22, 3.74, -1.5)

#### 2. String

Text values in single or double quotes (both work the same):
```
name = "Venkatesh"
name = 'Venkatesh'
``` 

#### 3. List []

Ordered collection of items (can have different data types):
```
a = [2.1, 100, "hello", "xxx", 99.9]
```

#### 4. Dictionary

Collection of key-value pairs. **Mutable** (changeable):
```
person = {"name": "ramesh", "age": 20, "college": "anna university"}
```

#### 5. Tuples

Ordered collection like lists, but **immutable** (cannot be changed after creation):
```
coordinates = (10, 20, 30)
```

#### 6. Set

Unordered collection of unique items (no duplicates): It can be changable **changable**
```
colors = {"red", "blue", "green"}
```

#### 7. Boolean

True or False values. Used in conditions and comparisons:
```
is_valid = True
is_empty = False
```
