# Recap — Very Short Cheat Sheet

- Variables: store values (int, float, str, bool).
- Collections: list (ordered, changeable), tuple (ordered, fixed), set (unique), dict (key->value).
- Control flow: `if`, `elif`, `else`, `for`, `while`.
- Functions: `def name(params):` → reuse code.
- Modules: `.py` files; packages are folders with `__init__.py`.

- Loops: `for` (iterate items), `while` (repeat while condition). Use `break`/`continue`.
- Error handling: `try` / `except` to catch errors; `finally` always runs; use `raise` to throw.

Keep this file handy as a one-line reminder.
